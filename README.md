# Hypergate GTM Context OS

The working repo for the Hypergate go-to-market team at Papers AG. It holds the context Claude and the team need to produce GTM work for Hypergate (https://hypergate.com): ICP, positioning, messaging, brand kit, research, playbooks, learnings, meeting notes and campaign output, plus weekly priorities and a running work log.

Start with `CLAUDE.md` for how the folders work and the rules every piece of work follows. Secrets go in `.env`, which is never committed.
